# Dashboard and Insights Separation

## Overview role

Overview is an executive dashboard: four KPI tiles, one primary price-distribution chart, a safety-share card, a compact manufacturer ranking, and a five-item savings leaderboard. It contains labels and live values but no long-form interpretation.

## Insights role

Insights remains the project’s explainability layer. It owns the advanced analytical charts, chart-by-chart interpretation, caveats, and evaluator narrative.

## Visual continuity

No design tokens change. The existing cobalt system, typography, spacing, motion, logo, card treatment, and chart components are reused. The only change is information hierarchy and density.

# Premium Interface Redesign

## Direction

The interface will use a refined editorial-clinical SaaS aesthetic: softly layered surfaces, restrained glass effects, deeper shadows, 22–24px card geometry, Manrope typography, DM Mono metadata, and one consistent Lucide outline icon family. Teal remains the product signature while coral, amber, and blue appear only as semantic data accents.

## Shared system

- Cards gain elevation, hover lift, generous padding, and consistent radii.
- KPI values use tabular figures, count-up motion, tighter label/value rhythm, and semantic accent badges.
- The top bar gains a route-aware breadcrumb, sync timestamp, theme toggle, and project avatar.
- Loading uses skeleton compositions; empty and error states remain explicit.
- Custom scrollbars, focus rings, tooltip affordances, animated page entry, and polished controls apply globally.
- Light and ink-green dark themes share the same semantic variables.

## Page changes

- Overview: labeled axes, gridlines, value labels, multi-accent charts, fixed manufacturer overflow, chart hover cue.
- Finder: elevated live-search state, explanatory interaction tooltip, calm severity meter, styled description overflow, icon tags, and scannable alternative cards with avatars and consistent savings precision.
- Manufacturers: custom select shell, non-redundant KPIs, intentionally reused market-gradient semantics, and a fuller live/not-listed panel.
- Savings: visible minimum-brand filters, sort control, striped ranking rows, tier-colored range marks, and polished scroll areas.
- Safety: integrated donut labels, explicit axis titles, muted correlation treatment, and typographic quotation styling.
- EDA: balanced three-part narrative grid, quantified preprocessing progress, highlighted evidence, and reduced paragraph density.

## Behavior

Navigation, cards, rows, charts, KPI numbers, controls, and search results animate with short restrained transitions. Reduced-motion preferences disable nonessential movement. All existing Supabase API contracts remain unchanged.
